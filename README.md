# One-Sentence Absurd Invention Pitch

A single-sentence pitch for a ridiculous invention that fixes a tiny everyday annoyance: a toothpaste tube that squeezes itself from the bottom and files a formal complaint every time you grab the middle, citing three years of unreported crimes against dentistry.

`main.py` writes the pitch to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).
